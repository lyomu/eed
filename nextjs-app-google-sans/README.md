# EED Research Institute — Google Sans variant

A copy of [`../nextjs-app`](../nextjs-app) with every font role (titles, body,
labels) set to Google Sans instead of DM Sans and Outfit. Same content and
Prismic repository. It is for comparing designs and is not deployed. Code
changes made in `nextjs-app` are not applied here automatically.

```bash
cp ../nextjs-app/.env.local .env.local   # or fill in from .env.local.example
npm ci
npm run dev                              # http://localhost:3001
```

Everything else is documented in the [repository README](../README.md).
